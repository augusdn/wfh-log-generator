# Security policy

## Supported version

Only the current default branch and deployed GitHub Pages version are supported.

## Reporting

Please use GitHub's private vulnerability reporting feature for this repository when available. Do not include personal records, generated CSV files, credentials, or other sensitive data in a public issue.

## Scope

The app is static and client-only. A report is especially useful if it demonstrates data leaving the browser, persistent storage without an explicit download, execution of untrusted input, bypass of the filename/date validation, or loading of an unexpected remote resource.
