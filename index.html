Australian WFH Log Generator

Create a synthetic work-from-home CSV using the selected financial year and state public holidays.

Processed only in this tab. Form values and CSV data are not sent to or stored by a server. There are no analytics, cookies, accounts, backend requests or browser storage. This page and its source code are public.

Synthetic planning data only

Generated records are not verified employment, payroll, legal or tax evidence. Check every entry against actual contemporaneous records before use or submission.

02

Daily working-time generation

For each eligible WFH day, duration is selected independently and uniformly at whole-minute precision between the inclusive minimum and maximum. Start time is selected independently between the inclusive earliest and latest times. Supplying a seed makes both sequences deterministic.

03

Leave periods

Add annual or sick/personal leave. Overlapping and adjacent ranges are allowed; excluded work dates are de-duplicated.

Dates must be inside the selected financial year. Weekends, public holidays and other already-excluded dates do not count as excluded work dates.
04

        05

        Reproducibility and output

        The same web seed and settings produce the same CSV bytes.

        This app uses a stable Mulberry32-based deterministic generator. It differs from Python's Mersenne Twister, so matching seed values do not produce byte-identical Python output.
